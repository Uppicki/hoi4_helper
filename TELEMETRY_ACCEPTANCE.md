# Приёмка V3: собственные противники по войнам

Дата проверки: 17 октября 2026 года (Москва).
Ветка: codex/player-war-overview.

## Результат

Передача мирного и военного наблюдения подтверждена реальной игрой.
Программные проверки и осмотр пяти рендеров приложения завершены; запуск
Windows-сборки и её текстовое содержимое подтверждены. Сверка положительного списка с интерфейсом
HOI4 не завершена: пользователь интерфейс не проверял, автоматический захват
окна вернул FrameArrived timed out: timed out waiting on channel; после
повторного выбора окна активация вернула failed to activate captured window.
После этих ошибок ввод в игру не выполнялся. Запрошен скриншот обзора войны.

## До и после

До V3 приложение показывало только показатели своей страны из V1/V2.
Теперь один полный кадр V3 содержит также прямых противников игрока и их
счётчик. Читатель проверяет дату, TAG, части, уникальность противников и
совпадение счётчика до публикации. Сырые мировые поля проходят отдельный
слой знаний; экран получает разрешённую проекцию. Неполный новый кадр
не дополняется данными прежнего. Мир, неизвестность, неподдерживаемый
формат и ошибка различаются. Отсутствие страны в перечне не означает false.

## Проверки текущего дерева

Flutter-команды выполнены через bundled Dart и flutter_tools.snapshot из
P:/sdk/flutter/v3_24/flutter; обычная обёртка может ждать блокировку SDK.

| Проверка | Результат |
| --- | --- |
| flutter test, весь каталог test | 70/70, All tests passed!, exit 0 |
| flutter analyze | No issues found!, exit 0 |
| dart format --output=none --set-exit-if-changed, 12 изменённых Dart-файлов | 0 changed, exit 0 |
| git diff --check | exit 0; только предупреждения Git о переводах строк |
| flutter build windows --release --no-pub | Built build/windows/x64/runner/Release/hoi4_helper.exe, 120,2 с, exit 0 |

В повторной приёмке текущая Release-сборка успешно запущена через computer-use
из build/windows/x64/runner/Release/hoi4_helper.exe. Экземпляр из чужого
.worktrees/focus-ui не использовался. Дерево доступности работающего приложения
подтвердило ITA, ETH, дату 1936.03.12.09, время получения, полное наблюдение
и предупреждение об отсутствии обновлений на паузе. Это функциональная проверка
реального окна, а не снимок его внешнего вида.

Захват изображения приложения дважды завершился ошибкой: FrameArrived timed out:
timed out waiting on channel; после обновления выбора и активации окна —
window capture timed out: timed out waiting on channel. По правилу восстановления
computer-use повторные захваты этого окна прекращены. Дерево доступности HOI4
содержит только корневую панель; список участников из него прочитать невозможно.

### Проверка внешнего вида приложения рендерами Flutter

Временный harness .dart_tool/telemetry_acceptance/visual_capture_test.dart
отрисовал реальный TelemetryScreen и тему HoiAssistantApp с обезличенным
военным кадром через настоящий читатель. Названия ALB/BUL заданы тестовым
словарём, текстовый шрифт — системный Arial; MaterialIcons загружен из активов
Release-сборки. Это рендер виджетов, не захват Windows и не изображение HOI4.

Осмотрены пять PNG; 5/5 проверок завершились с exit 0, исключений компоновки нет:

- war_wide.png: 1280×1000, полный кадр и ожидание следующего дня;
- war_narrow.png: 390×1000, тот же кадр на узком экране;
- incomplete_narrow.png: 390×1000, неполный набор;
- no_log_narrow.png: 390×1000, отсутствует лог;
- no_mod_narrow.png: 390×1000, в логе нет записей мода.

Статусы, дата и время получения, неподтверждённая сессия, список противников
и пояснение о паузе читаются; наложений и обрезанного текста в проверенной
области нет. Нули и прочерки визуально различимы, значки отображаются.
PNG находятся локально в .dart_tool/telemetry_acceptance/visual/ и не входят
в коммит. Сверка списка с интерфейсом самой игры остаётся непроверенной.

Регрессионные тесты охватывают частичные/повреждённые кадры, невозможные даты,
смену страны и откат даты, исчезновение/обрезку/замену лога, замены того же
и большего размера, гонки чтения, очистку прежней проекции, совместимость V1/V2,
неизвестные политики, границы знаний и неизменность разрешённых данных при
изменении скрытых полей. Военный реальный образец дополнительно проверяется
с удалённой relation при enemies=1 и последующим полным кадром.

## Оставшиеся ограничения

Это частичный обзор собственных противников, а не весь мир. В запущенной игре
не проверены несколько противников, изменение состава войны, откат загрузки,
смена страны и ротация лога; соответствующие переходы проверены тестами.
Сверка видимости противника в интерфейсе HOI4 остаётся открытой.

Телеметрия остаётся источником просмотра без проверенного ID кампании/сейва,
без объединения с сохранениями, рекомендаций и экспорта. Парсер сейвов
не расширялся. Следующий небольшой шаг — завершить сверку интерфейса по
скриншоту; дальнейшее расширение обзора требует отдельного согласования.

Чужие .metadata, .vscode/, web/ и работа в .worktrees/focus-ui не изменялись.
Исходные сохранения и файлы установки игры не изменялись. Полные игровые
журналы и числовые значения в репозиторий не добавлены.
