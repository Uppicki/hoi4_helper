# HOI IV Assistant

Локальный помощник для Hearts of Iron IV: Flutter-интерфейс для Windows и собственное Dart-ядро.

На текущем этапе доступны выбор папки системным диалогом или вводом пути, список файлов `.hoi4` (без вложенных папок), ручное обновление списка и чтение выбранного файла. Сохранения сортируются по времени изменения, новые сверху. Исходные файлы не изменяются; чтение потоковое, без хранения всего файла в памяти. Изменение размера или времени файла при чтении вызывает ошибку и предложение повторить загрузку.

Режимы: «Помощник» с заглушкой анализа и «Только просмотр». Парсинг, игровая дата, страна, рекомендации, автоматическое обнаружение игры, отслеживание новых сохранений и запоминание настроек ещё не реализованы. Успешное чтение файла не подтверждает поддержку его игрового формата или завершённость записи: проверки размера и времени выявляют изменения только во время чтения.

## Запуск

Из этой папки, с установленным Flutter SDK и инструментами сборки Windows:

```powershell
flutter pub get
flutter run -d windows
```

## Проверки

```powershell
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build windows --debug
```

`lib/core` содержит чтение файлов без зависимостей от Flutter. `lib/ui` содержит состояние экрана и виджеты. Личные сохранения и полные игровые данные не добавлять в репозиторий.
