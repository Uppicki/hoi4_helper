# HOI IV Assistant

Локальный помощник для Hearts of Iron IV: Flutter-интерфейс для Windows и собственное Dart-ядро.

При запуске открывается выбор загрузки: папка через системный диалог или ввод пути, список файлов `.hoi4` (без вложенных папок) и ручное обновление. Сохранения сортируются по времени изменения, новые сверху. Выбор файла автоматически загружает предпросмотр справа; кнопка «Использовать» или свайп влево открывает главный экран «Состояние мира». Вверху справа расположена краткая карточка сейва: по нажатию открываются размер, время изменения и чтения, версия формата и кнопка «Изменить источник». Она ведёт на страницу выбора источника; сейчас там доступен один вариант — файл сохранения, после выбора открывается список сейвов. На широком экране левая панель остаётся на месте при переходах. Если быстро выбрать другой файл или сменить папку, устаревший результат чтения не показывается. Исходные файлы не изменяются: сначала файл проверяется потоковым чтением, затем полностью разбирается в отдельном изоляте Dart.

Режимы: «Помощник» с заглушкой анализа и «Только просмотр». Главный экран показывает страну, идеологию, игровую дату, сложность и версию игры, затем карточки армии, флота, авиации, промышленности, ресурсов, фокусов, исследований, специальных проектов и карты. Из сохранения доступны дивизии, флоты, корабли, производственные линии, уровни заводов, политическая и командная власть, опыт армии и авиации, фокусы и технологии. Опыт флота и топливо не извлекаются. Число авиакрыльев, сырьевые ресурсы и специальные проекты пока не определяются: карточки честно показывают отсутствие данных. Для других стран интерфейс показывает только общедоступные названия и владение штатами. Это снимок на момент сохранения, а не непрерывное чтение текущей игры.

Коды стран, штатов, идеологий, зданий, технологий и фокусов переводятся через файлы локализации установленной игры. На главном экране можно выбрать русский или английский язык; неизвестный ключ показывается как код. Игра ищется в стандартном каталоге Steam и в `games/Hearts of Iron IV` на текущем диске; путь можно задать переменной окружения `HOI4_GAME_PATH`. Полные файлы локализации не добавляются в приложение. Получение состояния проходит через `WorldStateSourceFactory` и интерфейс `WorldStateSource`; сейчас зарегистрирован файловый источник. Собственный парсер извлекает подтверждённые поля из бинарного `HOI4bin` с `save_version=31` (проверено на сейвах игры 1.18). Другие версии бинарной схемы и текстовые сохранения пока не поддерживаются. «Людская сила в штатах» — сумма поля `manpower_pool.available` принадлежащих стране штатов, а не общий резерв армии; уровни фабрик не учитывают повреждения. Рекомендации, отслеживание новых сохранений и запоминание настроек ещё не реализованы.

## Запуск

Из этой папки, с установленным Flutter SDK и инструментами сборки Windows:

```powershell
flutter pub get
flutter run -d windows
```

## Проверки

```powershell
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build windows --debug
```

`lib/core` содержит чтение файлов без зависимостей от Flutter. `lib/ui` содержит состояние экрана и виджеты. Личные сохранения и полные игровые данные не добавлять в репозиторий.
