# HOI IV Assistant

Локальный помощник для Hearts of Iron IV: Flutter-интерфейс для Windows и собственное Dart-ядро.

При запуске открывается основной экран с телеметрией — первым, приоритетным источником данных. Мод раз в игровой день пишет в `game.log` дату, страну игрока и документированные числовые показатели своей страны: политику, заводы, топливо, сырьё, войска, исследования, запасы снаряжения и накопленную статистику строительства и производства. Приложение применяет данные только после получения полного набора за один игровой день. В V3 добавлен частичный обзор собственных войн: страны-противники из одного полного кадра проходят через отдельный слой знаний игрока. После установки проверены реальные мирные и военные записи V3, включая одного противника и счётчик. Соответствие положительного списка интерфейсу игры пока не проверено. Во время паузы обновления нет. Запись не привязана к конкретному сохранению и пока не используется для советов.

Через «Изменить источник» можно выбрать второй вариант — сохранения. Папка выбирается системным диалогом или вводом пути; файлы `.hoi4` (без вложенных папок) сортируются по времени изменения, новые сверху. Выбор файла загружает предпросмотр справа; кнопка «Использовать» или свайп влево открывает экран «Состояние мира». Краткая карточка сейва показывает размер, время изменения и чтения, версию формата и кнопку смены источника. На широком экране левая панель остаётся на месте при переходах. Если быстро выбрать другой файл или сменить папку, устаревший результат чтения не показывается. Исходные файлы только читаются: сначала файл проверяется потоковым чтением, затем разбирается в отдельном изоляте Dart.

Режимы: «Помощник» с заглушкой анализа и «Только просмотр». Основной экран показывает карточки армии, флота, авиации, промышленности, ресурсов, фокусов, исследований, специальных проектов и карты. При выборе телеметрии известные значения заполняют карточки, а дополнительные данные раскрываются в таблицах. Отсутствующие значения показаны прочерками, ошибочные — помечены отдельно; старый формат мода по-прежнему даёт только страну, дату и людские резервы. Источник, единицу и область значений каждого показателя описывает [контракт телеметрии](TELEMETRY_CONTRACT.md). При выборе сохранения экран показывает доступный снимок на дату файла. Из сохранения доступны дивизии, флоты, корабли, производственные линии, уровни заводов, политическая и командная власть, опыт армии и авиации, фокусы и технологии. Опыт флота и топливо из сохранения не извлекаются. Число авиакрыльев и специальные проекты пока не определяются. Для других стран интерфейс показывает только общедоступные названия и владение штатами. Это снимок на момент сохранения, а не непрерывное чтение текущей игры.

Коды стран, штатов, идеологий, зданий, технологий и фокусов переводятся через файлы локализации установленной игры. На экране снимка можно выбрать русский или английский язык; неизвестный ключ показывается как код. Игра ищется в стандартном каталоге Steam и в `games/Hearts of Iron IV` на текущем диске; путь можно задать переменной окружения `HOI4_GAME_PATH`. Полные файлы локализации не добавляются в приложение. Полный снимок проходит через `WorldStateSourceFactory` и интерфейс `WorldStateSource`; телеметрия читается отдельно и не подменяет снимок сохранения. Собственный парсер извлекает подтверждённые поля из бинарного `HOI4bin` с `save_version=31` (проверено на сейвах игры 1.18). Другие версии бинарной схемы и текстовые сохранения пока не поддерживаются. «Людская сила в штатах» — сумма поля `manpower_pool.available` принадлежащих стране штатов, а не общий резерв армии; уровни фабрик не учитывают повреждения. Рекомендации, отслеживание новых сохранений и запоминание настроек ещё не реализованы.

Панель национального фокуса открывает дерево из `common/national_focus` установленной игры. Для сохранения дерево ищется по записанному в нём ID, текущий и завершённые фокусы выделяются. Для телеметрии показано возможное дерево по тегу страны: мод пока не передаёт выбранное дерево, текущий фокус и прогресс. Если рядом с её `game.log` есть полный список активных DLC в `system.log`, несовместимые по `allow_branch` ветки и их зависимые фокусы скрываются; интерфейс указывает, что список DLC относится к последнему запуску. DLC текущего запуска не применяются к отдельному сохранению. Непроверенные условия видимости сохраняются как неизвестные и отмечаются «?». Ссылки локализации вида `$ключ$` раскрываются с защитой от циклов. Оставшиеся дни и следующий фокус неизвестны; общие, динамические ветки и изменения модов могут отсутствовать. Файлы игры только читаются.

Внизу слева на экране дерева расположена мини-карта. Нажатие или перетаскивание на ней перемещает основной вид с сохранением масштаба; рамка показывает текущую видимую область.

## Запуск

Из этой папки, с установленным Flutter SDK и инструментами сборки Windows:

```powershell
flutter pub get
flutter run -d windows
```

## Проверки

`dart run tool/check_telemetry.dart` проверяет чтение текущего `game.log` установленного мода и выводит версию, дату, количество показателей, состояние проекции обзора войн и число разрешённых противников без значений показателей. Числовой просмотр поддерживает V1/V2/V3; отношения V3 проходят отдельный слой знаний игрока.

```powershell
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build windows --debug
```

`lib/core` содержит чтение файлов без зависимостей от Flutter. `lib/ui` содержит состояние экрана и виджеты. Личные сохранения и полные игровые данные не добавлять в репозиторий.

## Контракт снимка

У каждого прочитанного сохранения есть SHA-256 содержимого, версия схемы снимка и явный статус идентификатора кампании. Пока принадлежность к одной кампании и соответствие игровых данных не подтверждены, два файла нельзя автоматически считать последовательными состояниями. Набор полей экрана и их происхождение описаны в [SNAPSHOT_CONTRACT.md](SNAPSHOT_CONTRACT.md).
