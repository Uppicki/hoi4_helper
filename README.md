# HOI IV Assistant

Локальный помощник для Hearts of Iron IV: Flutter-интерфейс для Windows и собственное Dart-ядро.

На текущем этапе доступны выбор папки системным диалогом или вводом пути, список файлов `.hoi4` (без вложенных папок) и ручное обновление списка. Сохранения сортируются по времени изменения, новые сверху. Выбор файла автоматически загружает его предпросмотр справа; кнопка «Использовать» или свайп влево открывает страницу «Состояние мира». Свайп вправо возвращает к списку; на широком экране левая панель остаётся на месте во время перехода. Если быстро выбрать другой файл или сменить папку, устаревший результат чтения не показывается. Исходные файлы не изменяются; чтение потоковое, без хранения всего файла в памяти. Изменение размера или времени файла при чтении вызывает ошибку и предложение повторить загрузку.

Режимы: «Помощник» с заглушкой анализа и «Только просмотр». Предпросмотр поддерживаемого бинарного сохранения показывает игровую дату, страну игрока, идеологию, сложность и версию игры. Страница мира пока показывает эти метаданные и места для будущих разделов. Это снимок на момент сохранения, а не непрерывное чтение текущей игры.

Получение состояния проходит через `WorldStateSourceFactory` и интерфейс `WorldStateSource`. Сейчас зарегистрирован файловый источник; другой источник (например, MCP) можно добавить через настройки источника и регистрацию фабрики без изменения контракта контроллера. Файловый источник извлекает только метаданные заголовка `HOI4bin` по проверенной на реальных сохранениях структуре версии 1.18. Остальные части игрового мира, другие бинарные схемы и текстовые сохранения пока не разбираются и возвращают явную ошибку. Рекомендации, автоматическое обнаружение игры, отслеживание новых сохранений и запоминание настроек ещё не реализованы. Проверки размера и времени выявляют изменения только во время чтения; они не подтверждают, что весь игровой формат поддерживается.

## Запуск

Из этой папки, с установленным Flutter SDK и инструментами сборки Windows:

```powershell
flutter pub get
flutter run -d windows
```

## Проверки

```powershell
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build windows --debug
```

`lib/core` содержит чтение файлов без зависимостей от Flutter. `lib/ui` содержит состояние экрана и виджеты. Личные сохранения и полные игровые данные не добавлять в репозиторий.
