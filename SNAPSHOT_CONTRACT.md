# Контракт снимка состояния, схема 1

Снимок представляет одно полностью прочитанное сохранение. `gameDate` — игровая дата внутри файла; `readAt` — время его чтения компьютером. Экран не получает непрерывное состояние запущенной игры.

## Проверенные источники

На локально установленной игре `Case Green v1.18.0.0.858d (3bae)` проверены заголовки нескольких сохранений стран GER и SOV с разными игровыми датами. Два полных сохранения GER разобраны собственным Dart-парсером без изменения исходных файлов. Формат образцов — `HOI4bin`, `save_version=31`. Исходные файлы не включены в репозиторий. Иные бинарные схемы и текстовые сохранения пока явно отклоняются. Эта версия игры является проверенным образцом, а не постоянным требованием проекта.

В заголовках есть UUID, который различается между файлами. Пока не доказано, что он обозначает кампанию. Поэтому `campaignId` остаётся неизвестным; совпадение страны, даты начала и версии игры не доказывает общую кампанию.

## Идентичность и замена

| Поле | Происхождение |
| --- | --- |
| `schemaVersion=1` | Версия контракта приложения. |
| `sourceId` | Абсолютный путь исходного файла. |
| `saveId` | SHA-256 всего содержимого файла. Хеш сверяется при разборе после первичного чтения. |
| `campaignId` | Неизвестно до обнаружения проверенного идентификатора кампании. |
| `playerTag`, `gameDate`, `gameVersion` | Заголовок сохранения. |
| `gameDataId` | Неизвестно до проверки установленной игры, DLC и модов. |
| `readAt` | Время файлового чтения, не игровая дата. |

Для автоматической замены нужны известные и одинаковые `campaignId`, `playerTag`, `gameDataId`, `gameVersion`, более поздняя игровая дата и другой `saveId`. Неизвестный идентификатор кампании или игровых данных запрещает такую замену. Более ранний сейв также не может заменить поздний. При ручном выборе нового файла контроллер отбрасывает результат незавершённого старого чтения.

## Происхождение полей экрана 0.1.0

`SnapshotEvidence` отмечает значения как полученные из сохранения (`save`), рассчитанные (`calculated`), полученные из файловой системы (`fileMetadata`), из установленной игры (`installedGameData`), неизвестные (`unknown`) или не поддерживаемые (`unsupported`). Отсутствие значения не преобразуется в 0 или `false`.

| Поля экрана | Происхождение и ограничения |
| --- | --- |
| Страна, идеология, сложность, игровая дата, версия игры, версия сохранения, дата начала, Ironman | Непосредственно из сохранения. |
| Количество стран, штатов, провинций, фракций | Подсчёт распознанных блоков и ключей сохранения. |
| Столица, крупная держава, стабильность, поддержка войны, корабли, опыт армии и авиации, политическая и командная власть, ячейки исследований | Непосредственно из данных страны игрока. |
| Дивизии, флоты, военные и морские производственные линии | Подсчёт распознанных блоков страны игрока. |
| Фабрики, военные заводы, верфи, штаты страны, людская сила в штатах | Подсчёт в принадлежащих стране штатах. Уровни зданий пока без учёта повреждений; людская сила в штатах не равна армейскому резерву. |
| Дерево, текущий и завершённые фокусы, активные и изученные технологии | Из данных страны. Пустой список пока не доказывает отсутствие и отмечается как неизвестный. |
| Название файла, размер, время изменения и чтения, SHA-256 | Файловая система и полное чтение файла. |
| Переведённые названия стран, штатов, зданий, фокусов и технологий | Локализация установленной игры; без перевода отображается код. |
| Авиакрылья, опыт флота, топливо, сырьевые ресурсы, армейский резерв, специальные проекты | Извлечение пока не реализовано. |

До шага 5 дорожной карты экран всё ещё использует разобранный мир. Данные других стран нельзя применять для советов или экспорта, пока не готов слой знаний игрока.
