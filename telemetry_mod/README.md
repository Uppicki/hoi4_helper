# Проверка телеметрии HOI4

Этот минимальный мод проверяет, может ли локальный помощник получать данные из запущенной игры без чтения памяти процесса. Раз в игровой день он пишет строку `HOI4_HELPER_V1` в пользовательский `logs/game.log`: игровую дату, тег страны игрока и её людские резервы. Мод не меняет игровое состояние. Формат строк проверен на локальной установленной версии 1.18.0; для других версий требуется отдельная проверка.

## Установка при запуске через hoi4.exe

1. Закройте игру перед проверочным запуском. Само копирование файлов можно сделать заранее, но запущенная игра не подхватит мод до перезапуска.
2. В папке `Документы/Paradox Interactive/Hearts of Iron IV/mod` разместите папку `hoi4_helper_telemetry` и файл `hoi4_helper_telemetry.mod` из этого каталога.
3. В соседнем файле `Документы/Paradox Interactive/Hearts of Iron IV/dlc_load.json` добавьте `mod/hoi4_helper_telemetry.mod` в массив `enabled_mods`, сохранив остальные моды и `disabled_dlcs`. Если файла нет, создайте его с содержимым:

   ```json
   {"enabled_mods":["mod/hoi4_helper_telemetry.mod"],"disabled_dlcs":[]}
   ```

4. Запустите `hoi4.exe`, откройте одиночную кампанию и пропустите один игровой день. Затем проверьте `Документы/Paradox Interactive/Hearts of Iron IV/logs/game.log` поиском `HOI4_HELPER_V1`. При отсутствии строки проверьте `logs/error.log` и фактический путь пользовательских данных.

Пока это только проверка транспорта. `on_daily` не вызывается во время паузы и не сообщает об изменениях немедленно. Лог не связывается автоматически с конкретным сохранением; до разработки идентификатора сессии и фильтра знаний игрока эти строки нельзя использовать для советов или экспорта. Моды могут менять контрольную сумму игры и доступность достижений.

Для удаления закройте игру, удалите только `mod/hoi4_helper_telemetry.mod` из `enabled_mods`, затем удалите эту папку и файл мода. Другие записи в `dlc_load.json` сохраните.
