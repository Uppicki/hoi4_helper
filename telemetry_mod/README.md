# Телеметрия HOI4

Мод раз в игровой день считывает только показатели страны игрока и пишет их в пользовательский `logs/game.log`. Текущая версия V2 выводит 221 числовое поле в 19 частях: политику, промышленность, топливо, сырьё, армию, исследования, запасы снаряжения и накопленную статистику. Приложение показывает только полный набор за одну игровую дату; неизвестные значения остаются пустыми. Старые строки V1 также читаются. Версии записи и схемы приложения, единицы, допустимые области и статусы полей описаны в [контракте наблюдения](../TELEMETRY_CONTRACT.md).

Мод создаётся из [каталога полей](../lib/core/telemetry_catalog.dart) командой:

```powershell
dart tool/generate_telemetry_mod.dart "P:\SteamLibrary\steamapps\common\Hearts of Iron IV"
```

Генератор сверяет переменные, ресурсы и типы снаряжения с файлами установленной игры. После обновления игры мод нужно сгенерировать повторно, обновить `supported_version` в обоих дескрипторах и проверить реальные строки журнала. Текущий V2 повторно сгенерирован по установленной игре 1.19.3.0: состав не изменился, 221 показатель в 19 частях. Для 1.19.3.0 проверена совместимость по игровым файлам; реальный вывод `game.log` ещё не проверен. Последний подтверждённый запуск с полным набором был на 1.18.0.

## Установка при запуске через hoi4.exe

1. Закройте игру перед проверочным запуском. Копировать мод можно заранее, но запущенная игра загрузит изменение только после перезапуска.
2. В папке `Документы/Paradox Interactive/Hearts of Iron IV/mod` разместите папку `hoi4_helper_telemetry` и файл `hoi4_helper_telemetry.mod` из этого каталога.
3. В соседнем `dlc_load.json` добавьте `mod/hoi4_helper_telemetry.mod` в массив `enabled_mods`, сохранив остальные записи. Если файла нет, создайте:

   ```json
   {"enabled_mods":["mod/hoi4_helper_telemetry.mod"],"disabled_dlcs":[]}
   ```

4. Запустите `hoi4.exe`, откройте одиночную кампанию и пропустите один игровой день. Ищите `HOI4_HELPER_V2|phase=begin` и `HOI4_HELPER_V2|phase=end` в `logs/game.log`. При отсутствии строк проверьте `logs/error.log`.

`on_daily` не срабатывает на паузе. Телеметрия не содержит проверенного идентификатора кампании или сохранения и не используется для советов и экспорта. Мод может менять контрольную сумму игры и доступность достижений. Для удаления закройте игру, удалите только `mod/hoi4_helper_telemetry.mod` из `enabled_mods`, затем удалите эту папку и файл мода.
